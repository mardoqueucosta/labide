# Imperial Toalheria - Site Clone

Clone completo e funcional do site [Imperial Toalheria](https://imperialtoalheria.com.br/)

## 📋 Descrição

Site de locação de toalhas de mesa, sousplat, guardanapos de tecido e acessórios para festas, aniversários, bodas e comemorações.

## ✨ Características

- ✅ Design responsivo (mobile, tablet e desktop)
- ✅ HTML5 semântico
- ✅ CSS3 moderno com Flexbox e Grid
- ✅ JavaScript vanilla (sem dependências)
- ✅ Animações suaves e transições
- ✅ Menu mobile hamburger
- ✅ Busca funcional
- ✅ Formulário de contato
- ✅ Botão de WhatsApp flutuante
- ✅ Scroll suave entre seções
- ✅ Lazy loading de imagens
- ✅ Botão "Voltar ao topo"
- ✅ SEO otimizado

## 🎨 Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização moderna
- **JavaScript** - Interatividade

## 🚀 Como Usar

1. **Clone ou baixe o repositório**

2. **Abra o arquivo `index.html` em seu navegador**
   ```bash
   # Usando Python
   python -m http.server 8000

   # Usando Node.js (http-server)
   npx http-server

   # Ou simplesmente abra o arquivo index.html diretamente
   ```

3. **Acesse no navegador**
   ```
   http://localhost:8000
   ```

## 🔧 Customização

### Alterar Cores
Edite as variáveis CSS no arquivo `css/style.css`:
```css
:root {
    --primary-color: #fcd21d;
    --secondary-color: #2ea3f2;
    /* ... outras variáveis */
}
```

### Alterar Conteúdo
Edite o arquivo `index.html` diretamente.

### Adicionar Produtos
No arquivo `index.html`, duplique a estrutura `.product-card` e atualize as informações.
